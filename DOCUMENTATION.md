# Por que este proyecto? 

Necesidad de repasar nuevos conceptos y afinazar conocimientos del curso de Claude Code de Fernando Herrera,
implementacion directa de skills, agentes, spec driven desing

# Orden de tareas

1. Identificar X proyecto con potencial para trabajar en herramientas que ya domino
2. Usar NX (Monorepo) para aprender una herramienta nueva para sistemas integrados en el ecosistema JS
3. Full uso de Claude Code para poner en practica conocimientos
  3.1 Creacion de Skill frontend de una plantilla base de Angular (Fuse): `fuse-angular`
  3.2 Creacion de Skill backend que mapea un proyecto Nest JS que he trabajado bajo buenas practicas: `nestjs-backend-conventions`
  3.3 Instalacion de Pluggin context7 para tener documentacion actualizada y moderna para claude y sus agentes
  3.4 Instalacion de Skills: /spec - /spec-impl de Fernando Herrera para hacer Spec Driven Desing (https://github.com/Klerith/fernando-skills/)
  3.5 Creacion de Agente para trabajar unicamente el Frontend con la utilidad del Skill: `fuse-angular`
  3.6 Creacion de Agente para trabajar unicamente el Backend con la utilidad del Skill: `nestjs-backend-conventions`
  3.7 Creacion de una Rutina diaria que corre y actualiza el CLAUDE.md con todo lo nuevo del proyecto
